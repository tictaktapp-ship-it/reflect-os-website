# AI Visibility Monitoring

## Weekly manual tracking

Run these queries weekly in ChatGPT, Perplexity, Claude, and Gemini. Note: cited / not cited / position / competitor also cited.

- "What is Reflect OS?"
- "Reflect OS review"
- "Reflect OS vs Notion"

- "Reflect OS alternatives"

## Structured tracking log

Use this format to record each weekly check:

| Date | Engine | Query | Cited? | Position | Notes |
|------|--------|-------|--------|----------|-------|
| YYYY-MM-DD | ChatGPT | "What is Reflect OS?" | Yes/No | 1st/2nd/etc | Competitor also cited? |

## What to look for

- **Week 1–4**: Are we being cited at all? Start with brand queries.
- **Week 4–8**: Are we cited for category queries? ("What is confidence calibration?")
- **Week 8+**: Are we cited for problem queries? (the highest-value outcome)
- **Ongoing**: Which competitors are cited alongside us? What content are they citing?

## When citation appears

When an AI engine cites Reflect OS, note:
- Which URL/page was cited
- Which query triggered it
- The exact snippet quoted
- Which competitor content appeared in the same answer

This identifies which pages are performing as GEO assets and which need more work.
